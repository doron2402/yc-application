# YC Application Output Template

Every field on the live form (`yc-form.md`), in form order, with the form's wording. Unknown facts stay as `❓ [what's needed]`, never invented. Weak answers from the interview are marked `🟡` inline so the founder sees them. Skip fields that don't apply (e.g. "When will you have a version people can use?" when already launched; "planned equity" when incorporated), and say so in one line.
